# Notebooks

Run notebooks from the project root after installing `requirements.txt`. They are short, source-backed explorations of the modules under `src/brightpath`; they do not contain the only implementation of any feature. The complete reproducible workflow is `python scripts/run_pipeline.py`.

The six notebooks cover data understanding, EDA/statistics, feature engineering, risk modeling, segmentation, and experimentation. Model outputs and figures in notebooks are generated from the seeded synthetic demo unless the notebook explicitly loads the optional UCI dataset.
